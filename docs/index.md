# TM1 v12 Book

An open textbook on **IBM Planning Analytics / TM1 v12**.

!!! note
    This book is unofficial and is not affiliated with or endorsed by IBM.

## What this book covers

- [Concepts](concepts/index.md): cubes, dimensions, hierarchies and how TM1 v12 fits together
- [Setup](setup/index.md): getting a TM1 v12 environment running
- [Modelling](modelling/index.md): designing cubes and dimensions
- [TurboIntegrator](turbointegrator/index.md): loading and transforming data with TI processes
- [Rules](rules/index.md): calculations and feeders
- [REST API](rest-api/index.md): working with TM1 v12 programmatically
